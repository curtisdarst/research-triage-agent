Research Triage Agent

ADK + BigQuery + Gemini. Every claim cited, unsupported claims flagged rather than guessed.

Every question below runs through four tools, in order:

  1. search_corpus embeds your question and finds the closest papers in BigQuery
  2. retrieve pulls their full abstract text
  3. synthesize (Gemini 3.1 Pro Preview) drafts a claim-by-claim answer citing the papers it used
  4. validate (Gemini 3.7 Flash) checks each individual claim against the actual text of the paper it cites

A claim only appears under "Findings" if validate confirms the cited abstract really supports it; anything it can't confirm is reported under "Could not verify" instead of being quietly dropped or guessed. Watch the trace table after you run a query, it shows all four calls, the model each one used, and what each one cost.

How ingest picks which papers to pull

Two filters, both applied by arXiv's own search API, not by anything semantic. First, category: the query below starts with cat:cs.SE OR cat:cs.CL OR cat:cs.AI, arXiv's own subject classification, set by the submitting authors. Second, phrase match on the abstract text: the rest of the query is an OR of specific phrase combinations (abs:"exact phrase"), and a paper is pulled in if any one of them appears literally in its abstract. There's no relevance ranking and no quality filter of any kind, matches are just sorted newest-first and the first N are taken. A paper that's obviously on-topic but phrased differently won't match; a paper that mentions a phrase once in passing will.

Edit the query below to point ingest at a different topic entirely, it's arXiv's query syntax: cat: for category, abs:"phrase" for an exact abstract phrase, AND / OR / parentheses to combine them. Left as-is, it re-runs the current topic (prompt engineering effects on LLM-generated code quality) and idempotently refreshes/extends today's corpus rather than duplicating it.

Clear the corpus

Deletes every paper currently stored, embeddings included. No undo except re-ingesting. Useful before switching to a genuinely different topic, since ingest only ever upserts, it never removes old off-topic papers on its own.

Ingest uses arXiv's public API for personal, non-commercial, open-source use, independent from arXiv: no arXiv branding or claimed affiliation, metadata only (titles, authors, abstracts, ids), no hosting or redistribution of PDFs or source files, and no more than one request every three seconds on a single connection (REQUEST_DELAY_SECONDS = 3.0 in ingest/arxiv_client.py). See arXiv's API access policy and Terms of Use. Thank you to arXiv for use of its open access interoperability.
