Research Triage Agent

Governed agentic RAG demo. ADK + BigQuery + Gemini. Every claim cited, unsupported claims flagged rather than guessed.

Every question below runs through four tools, in order: search_corpus embeds your question and finds the closest papers in BigQuery, retrieve pulls their full abstract text, synthesize (Gemini 2.5 Pro) drafts a claim-by-claim answer citing the papers it used, and validate (Gemini 2.5 Flash) checks each individual claim against the actual text of the paper it cites. A claim only appears under "Findings" if validate confirms the cited abstract really supports it; anything it can't confirm is reported under "Could not verify" instead of being quietly dropped or guessed. Watch the trace table after you run a query, it shows all four calls, the model each one used, and what each one cost.

Admin: ingest more papers into the corpus

Pulls up to the given number of papers from arXiv into BigQuery. Idempotent: papers already in the corpus get refreshed in place, nothing is duplicated. arXiv rate-limits fetches to about 1 request per 3 seconds per 100 papers, so a large run can take several minutes; this page will wait for it to finish rather than time out early.
